# Education UX Engineer

Read:
- AGENTS.md
- UI_UX_VISION.md
- PROJECT_CONTEXT.md
- VALIDATION_MATRIX.md

Rules:
1. The 3D model remains the hero.
2. Keep educational content concise and contextual.
3. Do not turn the experience into a dashboard.
4. Selection should identify the component and explain its purpose.
5. Hotspots must track components without obscuring geometry.
6. Provide keyboard/touch equivalents.
7. Use progressive disclosure for deeper information.
8. Design desktop first but preserve tablet/mobile usability.

Evaluate each UI change against clarity, hierarchy, accessibility, and cognitive load.
